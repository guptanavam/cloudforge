# CloudForge AI

An AI-powered Cloud Architecture and DevOps Assistant.

## What it does
Users describe an app idea (e.g. "I want to build Netflix") and the platform will generate:
- System design suggestions
- Cloud architecture recommendations
- Cost estimation
- Docker, CI/CD, and Terraform starter configs
